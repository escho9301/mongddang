# 초기 웹사이트 아카이브 (2023–2026)

브랜드가 "우리 동네 식자재 교환 커뮤니티"에서 "건강한 식문화 커뮤니티"로 피벗하기 전,
`mongddang.co.kr` 시절의 첫 웹사이트를 그대로 남겨둔 것이다.

- 주소: `https://www.mongddangsigtag.com/archive/`
- 원본: 루트의 `index-legacy.html` (교체 전 `index.html`)

## 왜 통째로 복사했나

`index-legacy.html` 만 남겨두면 **깨진다.** 이 페이지가 쓰던 `img/logo.svg` 를 새 사이트가
이미 새 로고로 덮어썼기 때문에, 루트 에셋을 그대로 참조하면 옛 사이트에 새 로고가 뜬다.
그래서 HTML·CSS·JS·이미지·`data.json` 을 전부 이 폴더 안에 복사했고,
로고는 git 히스토리에서 교체 전 버전을 복원해 넣었다.

Bootstrap 과 jQuery 도 CDN 대신 `vendor/` 에 로컬 사본을 둔다.
아카이브는 10년 뒤에도 열려야 의미가 있는데, CDN 주소는 그때까지 살아 있으리란 보장이 없다.

**결과적으로 외부 의존이 0건이다.** 루트 파일을 뭘 바꾸든 이 폴더는 영향을 받지 않는다.

## 원본과 달라진 점

원본을 건드린 곳은 다음 네 군데뿐이다.

1. 상단에 아카이브 안내 배너 추가 (인라인 스타일 — `style.css` 에 의존하지 않게)
2. `<meta name="robots" content="noindex, nofollow">` 추가
3. `<title>` 앞에 `[아카이브]` 표기
4. 죽은 도메인 `mongddang.co.kr` 을 가리키던 `canonical`/`og:url` 정정

## 링크를 걸지 않는다

새 사이트 어디에서도 이 페이지로 링크하지 않는다. 주소를 아는 사람만 들어오는 상태로 둔다.
푸터 등에 링크를 추가하지 말 것 — 피그마 디자인에 없는 요소이고, 의도적으로 감춘 것이다.

검색 노출을 막는 것도 같은 이유다. 브랜드가 피벗했으므로 "식자재 교환" 페이지가
검색 결과에서 현재 사이트와 경쟁하면 안 된다.

> `robots.txt` 로 막지 않은 이유: 크롤링을 차단하면 크롤러가 위의 `noindex` 를 읽지 못해
> 오히려 URL 이 색인에 남을 수 있다.
